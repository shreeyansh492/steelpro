    Coordinates, not pixels burned in

    Each mark stores its page, type, x/y, width/height and any path points in page units, plus colour and stroke. The renderer draws it back over the page at any zoom.

    The gate on "revision required"

    Delete every annotation and clear the comment box: the submit button locks and says why. A rejection with no reason helps nobody in the drawing office.

      An annotation belongs to one revision

      R3's marks carry revision_id = REV-R3 forever. They are never copied onto R4, because that would put words in the client's mouth about a drawing they haven't seen.

      Responses point back

      A PM reply references the annotation ID it answers, so "addressed in R4" stays traceable to the exact remark that caused the change.

      No overwrite, ever

      Uploading R4 marks R3 superseded and leaves the file, the decision and the timestamps untouched. Superseded revisions stay viewable for the audit trail.

          How a page reaches the browser

          Browser→HTTPS→Backend API→Authenticate→Authorise project + document→VPN→Windows file server→Stream→Viewer

          The browser asks for /documents/DOC-0041/revisions/R3/stream. It never learns a drive letter, a share name or a folder. The comparison view opens two of these streams and nothing else — no temporary merged file is written anywhere.
